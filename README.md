app-volumeMounts.yaml | generate a Kubernetes Pod manifest named app-volume running a single container named app with image "gcr.io/kuar-demo/kuard-amd64:1" exposing port 8080. Configure a readinessProbe that does an HTTP GET to path "/ready" on port 8080 with initialDelaySeconds 0, periodSeconds 2, failureThreshold 3, successThreshold 1. Add a hostPath volume named data that mounts host path "/var/lib/app" into the container at "/data" (use hostPath.type DirectoryOrCreate). Output only the Pod YAML manifest; do not create any resources. | creates a pod manifest with option to mount folder fronm the host inside the container | [app-volumeMounts.yaml](yaml/app-volumeMounts.yaml)
